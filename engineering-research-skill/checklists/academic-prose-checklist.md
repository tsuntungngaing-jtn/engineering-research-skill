# Academic Prose Checklist

**Run via `skills/academic-prose-gate` before delivery close-out when any narrative ships.**  
Upstream authority: [academic-scrub](https://github.com/tsuntungngaing-jtn/academic-scrub).

## Preconditions

- [ ] `academic-scrub` installed under Cursor/agent skills path
- [ ] Targets listed (README, validation/optimize narratives, captions, OPTION_CARD text as applicable)
- [ ] Backup created under `prose_scrub/backup_YYYYMMDD_HHMMSS/`

## Scrub pass

- [ ] Audit completed before edits (excerpt → function → keep/delete/rewrite)
- [ ] L0 interaction / prompt / draft narration removed
- [ ] L1 assignment / course / rubric-as-authority removed
- [ ] L2 assembly narration compressed; useful Fig/Table/Eq navigation kept
- [ ] L3 defensive / reviewer-response stacks reduced to scientific scope
- [ ] L4 filler / lab-notebook stacks reduced without inventing sophistication
- [ ] Residual scan done; retained defensive cues justified in log
- [ ] Three post-edit questions applied to each revised paragraph

## ERS invariants (must survive scrub)

- [ ] Numbers, units, equations, citation keys unchanged
- [ ] `origin=` / `digitized_estimate` / `NOT_RUN` / `INCONCLUSIVE` / `claim_id` preserved
- [ ] REPLICATE vs OPTIMIZED wording still explicit
- [ ] No promotion of pixel matches to paper-reported `VALIDATED`

## Close-out artifacts

- [ ] `prose_scrub/SCRUB_LOG.md` written
- [ ] Full manuscript scrub: Parts A–D available if user requested 审校 / 去AI腔终版
- [ ] Captions / in-figure text checked (or marked N/A)
- [ ] `final-delivery-checklist.md` prose items can be ticked
